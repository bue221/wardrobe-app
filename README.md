# Wardrobe

PWA mobile-first: armario local y outfits on-device. Visual: Caldera (`docs/design.md`). Producto: `docs/PRD.md`.

## Quick path

```bash
npm install
npm run dev
```

- Landing: `/`
- App: `/app`

## Stack

React 19 + Vite 8 + Tailwind v4. Datos en IndexedDB. IA opcional via WebLLM (WebGPU).
